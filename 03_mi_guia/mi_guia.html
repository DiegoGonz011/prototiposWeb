Diccionario Maestro de HTML

Introducción al lenguaje

HTML (HyperText Markup Language) es el lenguaje estándar que se utiliza para estructurar y presentar contenido en la web.

Etiquetas de Formato

Existen varios comandos para que la pagina web se ve mucho mas ordenada uno de esos es hr que crea una linea de division para que el texto se vea mas ordenado
Tambien existe otro llamado br que es un salto de linea para que el texto no este todo amontonado
